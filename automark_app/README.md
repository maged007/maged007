# تطبيق تقدير سعر السيارات المستعملة (الإمارات)

تطبيق Flutter عربي يقدّر سعر السيارة المستعملة في سوق الإمارات بناءً على:
البراند، الموديل، الفئة، سنة الصنع، المسافة المقطوعة، حالة السيارة، والمواصفات الإقليمية.

## طريقة الحساب (هجين: سيرفر حي + أوفلاين)
التطبيق يحاول **سيرفر التسعير** (بيانات السوق الحية، طريقة المقارنات) أولاً،
ولو غير متصل يرجع تلقائياً **للحساب المحلي الأوفلاين**:

**السيرفر (الأدق):** انظر مجلد `../backend` — يبدأ من وسيط أسعار السوق الحقيقية
لكل (موديل + سنة) ويعدّل حسب الفئة/المسافة/الحالة/المواصفات، ويرجّع عدد العينات ودرجة الثقة.

**الأوفلاين (احتياطي):** جدول `priceByYear` محلي لكل موديل + استيفاء خطي + نفس التعديلات.

### تشغيل التطبيق
```bash
flutter pub get
# أوفلاين فقط:
flutter run -d chrome
# موصول بالسيرفر (الأدق):
flutter run -d chrome --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

## التحكم في البيانات
كل البيانات والنسب في ملفات JSON قابلة للتعديل بدون لمس الكود:
- `assets/data/catalog.json` — البراندات/الموديلات/الفئات + جدول الأسعار الحقيقية لكل سنة (`priceByYear`) + سعر الجديد لكل فئة.
- `assets/data/pricing_config.json` — معاملات الحالة والمواصفات، الاستهلاك، عقوبة الكيلومترات، النطاق.

## التشغيل
```bash
flutter pub get
flutter run -d chrome   # أو على محاكي/موبايل
flutter test            # اختبارات حاسبة السعر
```

> ملاحظة: الأرقام لقطة من السوق وقت الإعداد؛ حدّثها في `catalog.json` عند الحاجة.
