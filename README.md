# Automark — مقدّر سعر السيارات المستعملة (السوق الإماراتي 🇦🇪)

نظام يقدّر سعر السيارة المستعملة في الإمارات، **مرساة على سعر الوكيل (الجديد) لكل فئة**،
ومعاير على **داتا حقيقية** من تطبيق Automark. الإصدار الحالي يغطّي **نيسان التيما**،
ومبني كـ **معيار قياسي** يتمدّد لأي موديل/براند بإضافة بياناته فقط.

> مصدر بيانات واحد (`data/market.json`) يستخدمه محرّك Python والواجهة العربية معاً → النتيجة متطابقة 100%.

---

## فكرة التسعير

```
السعر = سعر الوكيل[الفئة]            ← سعر 2026 الحقيقي لكل فئة
      × الاحتفاظ حسب العمر            ← منحنى إهلاك معاير من الداتا (أحدث سنة = نقطة وسط وكيل↔إعلانات)
      × معامل الكيلومترات             ← أكثر كم = أرخص / أقل = أغلى
      × معامل المواصفات               ← خليجي 100% / وارد ≈ 80%
      × معامل الحالة                  ← 100% لأعلى حالة (ممتازة) ثم يقل
```
> **القيمة قبل معامل الحالة = سعر السيارة في حالة "ممتازة".** الحالات الأقل تخصم منها.
> **كل المعدلات نِسب مئوية** في `data/market.json` → التعديل سهل جداً.

### الأرقام المستخلصة من داتا أوتومارك (272 إعلان نظيف)
| العامل | القيمة |
|---|---|
| الإهلاك السنوي | **−13.8%/سنة** (احتفاظ 86.2%) |
| أحدث سنة (نقطة وسط) | احتفاظ 88.9% من سعر الوكيل |
| الكيلومترات | −0.95% لكل 10,000 كم |
| وارد مقابل خليجي | **−20%** |
| 5 حالات | ممتازة 100% · جيدة جداً 92% · جيدة 85% · مقبولة 78% · ضعيفة 72% |

### سعر الوكيل — تيما 2026 (خليجي)
S: 110,500 · SR: 126,500 · SV: 129,500 · SL: 143,500 · Platinum: 147,000 درهم

## الدقة

على المحرّك المنشور مقابل **272 إعلان حقيقي** (شريحة "جيدة" مقابل الإعلانات مجهولة الحالة):
```
MdAPE (الخطأ الوسيط) = 12.1%      ← الأدل على السيارة النموذجية
داخل ±15% = 60%   |   داخل ±20% = 76%
```
> الخطأ المتبقّي طبيعي: الإعلانات أسعار **طلب** ولا تحتوي على الحالة/الحوادث/الأوبشن.

شغّل التقارير:
```bash
python3 scripts/calibrate.py altima    # تنظيف + انحدار + معايرة + تقرير (نِسب مئوية)
python3 scripts/validate.py            # تحقّق سريع على نقاط السوق
```

## بنية المشروع
```
data/raw/                 ← الداتا الخام من Automark
data/market.json          ← مصدر الحقيقة (سعر وكيل + معدلات بنِسب مئوية + نقاط تحقّق) — قابل للتعديل بسهولة
src/pricing_engine.py     ← محرّك التسعير (مرساة سعر الوكيل + 5 حالات + عزل البراند)
src/predict.py            ← أداة سطر الأوامر
web/index.html            ← الواجهة العربية (محرّك JS مطابق + بيانات محقونة)
scripts/calibrate.py      ← تنظيف + انحدار + معايرة موديل من داتا حقيقية
scripts/validate.py       ← قياس الدقة مقابل نقاط السوق
scripts/build_web.py      ← ربط البيانات بالواجهة (مصدر واحد)
tests/test_pricing.py     ← اختبارات الوحدة
```

### بنية البيانات (تعزل كل براند على حدة)
```
brands → nissan → default_retention_pct   (معدّل إعادة البيع القياسي للبراند)
                → models → altima → { سعر الوكيل، retention، km، spec، condition، floor، anchors }
```
المحرّك يقرأ `retention_pct` للموديل، وإلا `default_retention_pct` للبراند → **كل براند له معدّل
احتفاظ بقيمته مستقل** (نيسان غير تويوتا غير لكزس)، من غير تغيير في الكود.
