# Automark — مقدّر سعر السيارات المستعملة (السوق الإماراتي 🇦🇪)

مشروع يقدّر سعر السيارة المستعملة في الإمارات بأرقام **معايرة على إعلانات سوق حقيقية**
(دوبيزل، دوبي كارز، درايف عربية، كارسويتش، يالا موتور). الإصدار الأول يغطّي **نيسان**:
باترول، التيما، صني، إكس-تريل، كيكس.

> الفلسفة: مصدر بيانات واحد معاير (`data/nissan_market.json`) يستخدمه محرّك Python
> والواجهة العربية معاً، فالنتيجة متطابقة 100% في الاتنين.

---

## الدقة

نوعان من المعايرة حسب توفّر الداتا:

**1) التيما — معايرة من داتا حقيقية (data-driven):**
انحدار log-linear على **272 إعلان حقيقي** مصدّر من تطبيق Automark، بعد تنظيف قوي
(إزالة أسعار وكيلومترات شاذة، واستخراج السنة/الفئة/المواصفات من اسم الإعلان):

```
MdAPE (الخطأ الوسيط) = 11.4%      ← الأدل على السيارة النموذجية
داخل ±15% من السعر الحقيقي = 62%   |   داخل ±20% = 76%
```
> الخطأ المتبقّي طبيعي: داتا الإعلانات أسعار **طلب** ولا تحتوي على الحالة/الحوادث/الأوبشن،
> والتفاوت ده هو السقف الطبيعي للدقة.

**2) باقي الموديلات — معايرة من إعلانات السوق العامة** (نقاط تحقّق في ملف البيانات):
```
MAPE = 7.3%   على 17 نقطة معايرة   (الهدف < 15%)
```

شغّل التقارير بنفسك:

```bash
python3 scripts/calibrate.py altima       # تحليل + معايرة من داتا أوتومارك
python3 scripts/validate.py               # تحقّق سريع على نقاط السوق
```

---

## كيف يشتغل التسعير؟

السعر = **قيمة أساسية حسب العمر** (منحنى إهلاك لكل موديل) ثم تُضرب فيها معاملات السوق الإماراتي:

| العامل | الأثر |
|---|---|
| العمر | منحنى إهلاك: سقوط السنة الأولى + إهلاك سنوي لكل موديل |
| الكيلومترات | مقارنة بالمتوقع للعمر (خصم أكبر للزيادة، مكافأة أقل للنقص) |
| المواصفات | خليجي = أساس، أمريكي/مستورد أقل ١٠–١٥٪ |
| الحالة / الحوادث / الصيانة / عدد المُلّاك | معاملات إضافية |
| أرضية السعر | لا ينزل التقدير عن حد واقعي لكل موديل |

كل الأرقام والمعاملات شفافة وقابلة للتعديل في `data/nissan_market.json`.

## الاستخدام

### 1) سطر الأوامر (Python)

```bash
python3 src/predict.py --list
python3 src/predict.py --model patrol  --year 2019 --km 90000
python3 src/predict.py --model altima  --year 2021 --km 60000 --spec american --condition excellent
python3 src/predict.py --model kicks   --year 2022 --km 45000 --json
```

### 2) الواجهة العربية (ويب)

افتح `web/index.html` في أي متصفح — صفحة واحدة مكتفية بذاتها (offline)،
اختر الموديل والسنة والكيلومترات والمواصفات واضغط **احسب السعر**.

### 3) كمكتبة داخل كودك

```python
from src.pricing_engine import CarInput, estimate_price

est = estimate_price(CarInput(model="x-trail", year=2020, km=70000, spec="gcc"))
print(est.price, est.low, est.high)   # 51500 46500 56000
```

## بنية المشروع

```
data/raw/                 ← الداتا الخام المصدّرة من Automark (md)
data/nissan_market.json   ← مصدر الحقيقة (أسعار + منحنيات + معاملات + نقاط تحقّق)
src/pricing_engine.py     ← محرّك التسعير (يدعم override لكل موديل: مواصفات/كيلومترات)
src/predict.py            ← أداة سطر الأوامر
web/index.html            ← الواجهة العربية (محرّك JS مطابق + بيانات محقونة)
scripts/calibrate.py      ← تنظيف + انحدار + معايرة موديل من داتا حقيقية
scripts/validate.py       ← قياس الدقة مقابل نقاط السوق
scripts/build_web.py      ← ربط البيانات بالواجهة (مصدر واحد)
tests/test_pricing.py     ← اختبارات الوحدة
```

### معايرة موديل جديد من داتا Automark

1. صدّر الموديل كجدول md وحطّه في `data/raw/`.
2. أضِف إعداداته في `MODEL_CONFIG` داخل `scripts/calibrate.py` (سعر الجديد + حدود السعر).
3. شغّل `python3 scripts/calibrate.py <model> <path>` وانسخ الباراميترات الناتجة إلى `data/nissan_market.json`.
4. شغّل `python3 scripts/build_web.py` ثم الاختبارات.

- [ ] تويوتا (لاندكروزر، كامري، كورولا، يارس، برادو)
- [ ] باقي موديلات نيسان (باثفايندر، مكسيما، نافارا)
- [ ] براندات أوروبية/أمريكية
- [ ] تحديث دوري للأسعار من السوق
```
