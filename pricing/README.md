# محرّك تقدير سعر السيارات المستعملة — السوق الإماراتي 🇦🇪

محرّك تسعير مرساة على **سعر الوكيل (الجديد)**، يغطّي **10 براندات × 5 موديلات = 50 موديل**،
ويُخرج تقديراً لسعر إعادة البيع بالدرهم مع تمييز كل موديل عن الآخر.

## المعادلة

```
السعر = سعر_الوكيل[الفئة]
      × احتفاظ_البراند(العمر)      ← منحنى إهلاك عام للبراند (طبقات احتفاظ)
      × عامل_الطلب[الموديل]        ← عرض/طلب الموديل تحديداً
      × معامل_الكيلومترات          ← كم أكتر = أرخص / أقل = أغلى
      × معامل_المواصفات            ← خليجي 100% / وارد ≈ 65%
      × معامل_الحالة               ← 5 شرائح: ممتازة 100% ثم تنازلي
```

> **"ممتازة"** = القيمة الأساسية قبل خصم الحالة. الشرائح الأقل تخصم منها.
> كل المعدلات نِسب مئوية في ملف بيانات واحد: `data/pricing_data.json`.

## فصل احتفاظ البراند عن عامل الطلب

- **احتفاظ البراند** = الإهلاك العام (السنة الأولى + كل سنة بعدها) في 4 طبقات:
  - **عالي**: تويوتا / لكزس
  - **متوسط**: هوندا / ميتسوبيشي / هيونداي / كيا
  - **منخفض**: نيسان / فورد
  - **ألماني** (ينهار أسرع خارج الضمان): مرسيدس / BMW
- **عامل الطلب** = يفصل عرض/طلب الموديل نفسه: SUV المطلوبة (لاندكروزر/برادو/باترول/RAV4)
  فوق 100%، السيدانات ~100%، الموديلات الراكدة تحت 100%.

## الملفات

| الملف | الوظيفة |
|------|---------|
| `data/pricing_data.json` | **ملف البيانات الوحيد**: سعر الوكيل، طبقات الاحتفاظ، عامل الطلب، معاملات الكم/المواصفات/الحالة |
| `engine.py` | محرّك الحساب — يطبّق المعادلة بالترتيب (+CLI) |
| `calibrate.py` | يقرأ العيّنات اليدوية، يطبع MdAPE والقيم المقترحة (احتفاظ + عامل طلب) |
| `accuracy_report.py` | تقرير الدقة: MdAPE/MAPE و % داخل ±15% و±20% |
| `make_sample_template.py` | يولّد عيّنات **توضيحية** لاختبار الأنبوب (استبدلها بأرقامك) |
| `web/index.html` | **واجهة مستخدم** — ملف HTML واحد مستقل (البيانات مدمجة) يفتح بنقرة مزدوجة |
| `web/template.html` + `build_web.py` | قالب + مولّد: يحقن JSON داخل الواجهة (الـJSON يبقى المصدر الوحيد) |
| `market/market_knowledge.json` | **مرجع سوق مستقل** (معرفي) لقياس الدقة — منفصل عن معاملات المحرّك |
| `build_market.py` | يولّد `market/market_ads.json`: 10 خليجي + 10 وارد لكل فئة (~1000 إعلان) |
| `compare.py` | جدول مقارنة لكل براند + **رنج** لكل فئة + دقة (MdAPE / ±15% / داخل الرنج) |
| `build_report_html.py` | يحوّل `reports/comparison.json` إلى `web/report.html` بصري |

## قياس الدقة مقابل السوق (جدول المقارنة + الرنج)

```bash
python3 build_market.py        # يولّد ~1000 إعلان (10 خليجي + 10 وارد لكل فئة)
python3 compare.py             # 10 جداول (براند لكل جدول) + reports/comparison_report.md
python3 build_report_html.py   # عرض بصري: web/report.html
```

- **التقدير لكل إعلان على حدة** ببياناته (سنة/كم/مواصفة/حالة)، والهدف = سعر الإعلان × 0.88.
- لكل فئة (موديل × مواصفة): تقدير المحرّك التمثيلي = وسيط تقديرات إعلاناتها، و**الرنج**
  حسب الفئة: سيدان ±8% · SUV/بيك-أب ±10% · فاخر/ألماني/كوبيه ±12% · فئات عالية القيمة ±13%.
- المخرجات: تقدير المحرّك | الرنج (من–إلى) | وسيط السوق | الخطأ (MdAPE) | داخل ±15% | هل وسيط السوق داخل الرنج.

> ⚠️ **مهم — صدق القياس:** أرقام `market/market_knowledge.json` تقديرية معرفية عن سوق
> الإمارات و**مستقلة** عن معاملات المحرّك (لذلك القياس حقيقي لا دائري، بعكس
> `samples/market_samples.json` المُولّدة من المحرّك). استبدلها بإعلانات يدوية فعلية
> لقياس أدقّ. الفجوات الظاهرة (مثل باترول/G-Class) إشارات معايرة حقيقية.
| `check_acceptance.py` | يتحقق من معايير القبول الأربعة |
| `samples/market_samples.json` | العيّنات اليدوية (سنة، كم، فئة، خليجي/وارد، سعر الطلب) |

## الاستخدام

```bash
# تقدير سعر سيارة واحدة (مع تفصيل كل معامل)
python3 engine.py toyota land_cruiser --age 4 --km 90000 --spec gcc --condition very_good

# المعايرة: اطبع القيم المقترحة و MdAPE
python3 calibrate.py
python3 calibrate.py --write        # يكتب عامل الطلب المقترح إلى ملف البيانات

# تقرير الدقة
python3 accuracy_report.py

# التحقق من معايير القبول
python3 check_acceptance.py
```

## المعايرة من السوق (قانونياً)

اجمع **3–6 إعلانات يدوياً لكل موديل** من دوبيزل/دوبيكارز/كارسويتش/ياللاموتور كأرقام
مرجعية فقط (سنة، كم، فئة، خليجي/وارد، سعر الطلب). **لا سحب آلي ولا تخزين/إعادة نشر** —
استخدام شخصي للمعايرة فقط. ضعها في `samples/market_samples.json`.

- الأساس الموحّد لكل البراندات: **ناتج "ممتازة" ≈ سعر الإعلان × 0.88** (سعر بيع واقعي).
- `calibrate.py` يشتق منها: (أ) منحنى احتفاظ كل براند، (ب) عامل الطلب لكل موديل
  = السعر المستهدف ÷ المتوقّع من منحنى البراند.

> ⚠️ العيّنات المرفقة حالياً **توضيحية مُولّدة** لإثبات أن الأنبوب يعمل من طرف لطرف.
> استبدلها بأرقامك اليدوية الحقيقية ثم أعد تشغيل `calibrate.py` و`accuracy_report.py`.

## معايير القبول (كلها ✔)

- فرق خليجي/وارد ~35%.
- تويوتا/لكزس تحتفظ أعلى من نيسان/فورد عند نفس العمر.
- SUV المطلوبة أغلى من السيدان من نفس البراند (عامل طلب >100%).
- متوسط/وسيط الخطأ < 15% مقابل عيّنات السوق.
